# 🔮 Birthday Tarot - 给你的专属命运盲盒

这是一份送给朋友的生日礼物：一个融合了塔罗牌阵与盲盒机制的互动网页。
我没有直接把礼物递给他，而是把照片、回忆和祝福封存在了 16 张卡牌里。他可以通过**鼠标滑动**，或者直接**对着摄像头挥手**，像抽塔罗牌一样，翻开属于他的那份惊喜。抽完所有牌后，还会解锁一封隐藏的信件。

如果你也想给重要的人准备一份特别的礼物，欢迎直接拿走这份代码。无需懂复杂的编程，你只需要替换里面的图片和文字，就能打造属于你的专属盲盒。

---

## 🛠️ 如何定制你的专属礼物（小白必看）

项目已经为你做好了所有交互逻辑，**你只需要修改以下四处内容**，即可让它变成你的专属礼物：

### 1. 修改整体界面的文案
使用任何代码编辑工具（如 VS Code、记事本等）打开 `index.html` 文件，直接修改网页上显示的中文标题、副标题和提示语（搜索页面中显示的文本即可找到对应位置）。

### 2. 替换卡牌图片
项目中已经自带了初始的图片素材：塔罗牌背图 `back.png` 和示例礼物图（例如 `013.jpg`）。你可以直接使用这些原图，也可以自行替换成你自己的照片。

- 把你的照片或礼物图片准备好，一共需要 **16 张**。
- 将它们重命名为 `001.jpg`、`002.jpg`、`003.jpg`……以此类推。
- 把这 16 张图片放入项目文件夹中的 `birthweb/img/` 目录下，覆盖原文件即可。
- **💡 补充说明**：这 16 张牌里，照片卡和纯礼物卡的数量分配完全由你自己决定，只需要替换对应的图片即可。*如果你想要增加或减少卡牌的总数（比如改成 20 张），这涉及到代码逻辑的调整，请自行向 AI 提问修改。*

### 3. 修改卡牌背面的文字
打开 `index.html`，使用快捷键 `Ctrl + F`（Mac 为 `Cmd + F`）搜索 **`birthweb/img/`**。
在每一张卡牌对应的代码中，你会看到类似 `text: '填充文字'` 的地方。把“填充文字”替换成你写给朋友的祝福语即可。

### 4. 修改最终的信件
在 `index.html` 中搜索 **`填充信件内容`** 以及 **`填充信件标题`**。
找到对应的 `<p>` 标签，把里面的占位文字替换成你真正想对朋友说的话。保存刷新，就大功告成了！

## 🚀 改好之后，怎么发给朋友？

修改完图片和文字后，你有两种方式把这个惊喜送给对方：

**方式一：上线建站（推荐，最丝滑）**
因为项目是纯前端静态页面，不需要服务器和数据库。你可以使用免费的静态网站托管服务，例如：
- **Cloudflare Pages**、**Vercel**、**Netlify** 或 **GitHub Pages**。
- 注册账号后，直接把整个项目文件夹拖拽上传，平台会自动为你生成一个专属的网址链接。你可以把这个网址发给朋友，他在手机或电脑上点开就能直接体验。

**方式二：直接发压缩包（最简单）**
如果你不想折腾建站，也可以直接把这个项目文件夹打包成一个 `.zip` 压缩包发给对方。
让他解压后，双击里面的 `index.html` 文件，即可在浏览器中本地打开游玩。（注意：本地打开时，出于浏览器安全限制，手势识别可能无法调用摄像头，建议在本地使用鼠标模式游玩）。

## 💻 技术说明

- **交互实现**：支持鼠标拖拽与摄像头手势识别。手势识别引擎使用的是 **MediaPipe Hands**，通过调用设备摄像头识别手部关键点（握拳抽取、张开手掌收牌）。
- **前端技术**：原生 HTML / CSS / JavaScript，包含 3D 翻转、无限环形转盘与毛玻璃特效。
- **关于代码**：本项目的基础框架与逻辑由 **DeepSeek** 生成，并经过人工不断调试和修改。由于是 AI 辅助开发，代码中难免存在一些“屎山”或冗余部分，但**不影响正常运行与交互体验**。欢迎各位大佬提 PR 优化。
